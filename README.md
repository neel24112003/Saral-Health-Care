A modern, responsive, and high-performance healthcare web platform designed for hospitals, appointment booking, patient care services, and automated email inquiry handling with PHPMailer.

---

## ✨ Features

- 🏥 **Modern Healthcare UI**: Premium dark/light themes, smooth scrolling, glassmorphism design, and custom typography (Sora, Manrope, Inter).
- 📅 **Appointment & Inquiry Booking**: Interactive patient form for booking consultations and inquiries.
- ✉️ **Automated PHPMailer Integration**: Backend `mailer.php` script for seamless email notifications and updates.
- 📱 **Fully Responsive**: Optimized across Desktop, Tablet, and Mobile screens.

---

## 🛠️ Tech Stack & Languages

- **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Backend**: PHP (v8.x+)
- **Dependencies**: Composer, PHPMailer

---

## 🚀 Local Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/neel24112003/Saral-Health-Care.git
   cd Saral-Health-Care
   ```

2. **Install PHP Dependencies**:
   ```bash
   composer install
   ```

3. **Run Local Server** (via XAMPP / PHP built-in server):
   ```bash
   php -S localhost:8000
   ```
   Open `http://localhost:8000` in your browser.
